Banco de dados

Conectar o Supabase. Os dados, as fotos e as edições num banco de verdade.

São três passos e leva uns cinco minutos. Os dados que estão hoje no sistema vão para o banco sozinhos, e o GitHub continua guardando o código e um backup por dia.

1

Crie o projeto no Supabase

  1. Abra supabase.com/dashboard e entre (pode usar Continue with GitHub).
  2. Crie um projeto: nome blatt, uma senha qualquer para o banco (guarde-a) e a região South America (São Paulo).
  3. Espere um ou dois minutos até o projeto ficar pronto.
2

Crie a estrutura do banco

  1. Clique em Copiar SQL abaixo.
  2. No projeto, abra SQL Editor (menu da esquerda), cole o texto e clique em Run.
  3. Deve aparecer Success. No rows returned.
3

Cole o endereço e a chave

No projeto, abra Project Settings (engrenagem), depois Data API para o endereço e API Keys para a chave. Use a chave secret (começa com sb_secret_) ou, em projetos antigos, a service_role. Ela fica guardada só neste computador e nunca vai para o GitHub.

Termina em .supabase.co
Não use a chave publicável (sb_publishable_).
